## R6 最小安全契约 v1.0（已冻结）

### 规则 1：授权必须绑定具体操作
- 类型匹配：test 不能放行 delete，delete 不能放行 write
- 对象匹配：批准 file-A 不能放行 file-B
- 未授权操作不得在混合批次中搭便车

### 规则 2：执行端必须独立验证执行许可
- 验证：task_id、操作集合完整性、授权来源、范围、有效期、消费控制
- 保留：现有路径穿越保护、操作类型白名单、敏感路径保护
- 禁止：把客户端 nonce 或 task_state 字符串当作可信凭证

### 规则 3：授权、执行结果、任务终态是三个不同的事实
- 批准 ≠ 执行成功 ≠ 任务完成
- Worker 拥有权威 task_state，所有转换遵循 TaskModel_v2
- Node.js 不得修改 Redis 结果副本
