Webview JS (main.js)
这是整个前端的“大脑”，但它的逻辑非常简单：

它只做 4 件事：
① 连接 WebSocket
js
const socket = io("http://localhost:3000");
② 订阅任务
js
socket.emit("subscribe_task", taskId);
③ 接收 Worker v2 的结果
js
socket.on("task_result", (result) => {
  renderSteps(result.steps);
  renderEvents(result.events);
  renderContext(result.context);
  renderFinal(result.result);
});
④ 接收流式输出
js
socket.on("stream_chunk", (data) => {
  appendStreamingText(data.chunk);
});
它不做智能，不做推理，不做执行。
它只是：

把 Worker v2 的数据渲染到 UI 上。
        ↓
UI Components (steps / events / context / chat)
你可以把它理解为：

renderSteps() → 渲染步骤树

renderEvents() → 渲染事件流

renderContext() → 渲染中间结果

renderFinal() → 渲染最终结果

appendStreamingText() → 渲染流式输出

这些函数都非常简单：

示例：
js
function renderSteps(steps) {
  const container = document.getElementById("steps");
  container.innerHTML = "";

  steps.forEach(step => {
    const div = document.createElement("div");
    div.className = "step " + step.status;
    div.innerText = `${step.type} (${step.status})`;
    container.appendChild(div);
  });
}
