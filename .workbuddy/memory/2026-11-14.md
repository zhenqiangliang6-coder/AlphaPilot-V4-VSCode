## G10.9 联网核查纠错 + 日志治理（用户质疑后返工）

用户指出「魔塔免费、只有访问次数限制，不会欠费」。**核查确认用户正确，此前判断是方向性错误。**

### ModelScope 429 真相
- 官方《API-Inference 使用限制》：**免费**、非商业化非盈利；限制的是额度与并发。
- 官方《魔粒体系》：API-Inference 用魔粒抵扣（0.5/1/2 粒每次），每日登录领 200 + 绑定阿里云 50，短期魔粒 24h 过期、UTC+8 0 点重置；官方免费资源页写每日 2000 次累计调用。
- 第三方核验：魔粒**无人民币价值、无充值入口** → 用户无需充值。
- 社区实测：突发/单分钟限流会把 429 **误报**为 `insufficient balance`。
- 本机真实探针：`/v1/models` 200（Key/鉴权正常，38 模型，配置 6 个全在清单）；主模型 0/3/11s 三次 429，无 `Retry-After`；未支持模型返回 `400 has no provider supported`。
- 结论：`insufficient balance` = 当日免费魔粒不足或限流误报，**可恢复**。一天连跑 8 轮完整测试（每轮数百次 LLM 调用）足以打爆每日额度。恢复：次日 0 点 / 魔粒页点「领取」/ 降频。

### 修复 1：熔断方向纠错（`provider_health.py`）
旧版把 429 balance 永久熔断（进程内不恢复）→ 主线被切走且永不回头。改为 FATAL（401/402/403 quota，永久）/ QUOTA（429 balance，TTL 冷却默认 300s，到期 `is_open()` 自动半开）/ 普通 429 不熔断。`modelscope_client.py` 加 `_verify_quota_response()` 退避 2s 重试排除限流误报，冷却期间停止遍历 6 个降级模型。新增 `classify_response` / `kind` / `cooldown_remaining` / `trip_quota`。更正 `.env`、分类器、规划器、测试契约、CHANGELOG 里所有「欠费」措辞。契约 `test_provider_circuit.py` 18 passed。
