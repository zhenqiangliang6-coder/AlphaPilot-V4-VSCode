目的：根据 ARCHITECTURE_MANIFESTO 的原则，在新电脑为 Worker 创建受控虚拟环境并安装所需库，保证 Worker 在新环境中能成为“真相源头”。

文件：
- worker_requirements.txt — 聚合后的依赖清单（已生成）
- setup_worker_env.ps1 — Windows PowerShell 自动化安装脚本（已生成）

步骤（Windows）:
1. 克隆仓库并进入仓库根目录（包含 `python_worker`）。
2. 在 PowerShell 中运行：
   .\setup_worker_env.ps1
   （必要时以管理员身份运行或确保 Python 在 PATH 中）
3. 激活虚拟环境：
   & .\.venv_worker\Scripts\Activate.ps1
4. 运行测试以验证：
   pytest python_worker
   或者按项目实际入口启动 Worker（与旧电脑启动方式一致）。

注意事项（遵循 Architecture Manifesto）：
- 仅在受控的开发/测试环境中启用执行能力。
- 若为生产部署，应依照运维策略隔离执行能力和凭据。
