# AlphaPilot 前端功能测试指南 🧪

## 📋 测试前准备

### 1. 启动所有后端服务

```powershell
# 方法 1: 使用一键启动脚本 (推荐)
.\start_all.ps1

# 方法 2: 手动启动
# 终端 1: Node API
cd node-api
npm start

# 终端 2-4: Workers
cd python_worker
$env:WORKER_ID="qwen-worker-1"; python -m agents.qwen.qwen_worker_v2
$env:WORKER_ID="deepseek-worker-1"; python -m agents.deepeek.deepseek_worker_v2
$env:WORKER_ID="doubao-worker-1"; python -m agents.Volcengine.doubao_worker_v2
```

### 2. 编译扩展

```bash
cd vscode-extension
npm install
npm run compile
```

## 🐛 常见问题排查

### 问题 1: 代码补全不出现

**检查清单:**
```bash
# 1. 确认文件类型在支持列表中
# 2. 检查 VSCode 设置
code --list-extensions | grep alphapilot

# 3. 查看开发者工具
# Help → Toggle Developer Tools → Console
# 查找错误信息
```

**解决方案:**
- 确保输入至少 3 个字符
- 等待 500ms (防抖时间)
- 检查 Node API 是否运行: `curl http://localhost:3000/health`

### 问题 2: WebSocket 连接失败

**症状:** 控制台显示 "WebSocket 连接失败"

**解决:**
```bash
# 检查端口占用
netstat -an | findstr "3000"

# 重启 Node API
cd node-api
npm restart
```

### 问题 3: 任务一直 pending

**诊断:**
```bash
cd python_worker
python diagnose_workers.py
```

**常见原因:**
- Worker 未启动
- WORKER_ID 冲突
- 队列名称不匹配
